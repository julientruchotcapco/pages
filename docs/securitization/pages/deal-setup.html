Deal setup

Register the deal once. Its tranches, facilities and every monthly ingestion (identified by the pool cut-off date) are attached to it, and the details are kept as an audit snapshot with each ingestion run.

Deal details

Only the deal name is mandatory and it must be unique. Select one or more asset classes when the deal contains mixed collateral. The pool cut-off date is captured for each monthly ingestion on File setup.

Data model separationDeals, tranches and facilities are written to the deal register (deals, deal_tranches, deal_facilities). The dbo.loans table contains only loans_id and the supplied standard loan fields; each ingestion run records its deal and pool cut-off date.
