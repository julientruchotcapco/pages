Analytical model guide

RMBS credit model steps

A concise explanation of the calculation layers used by this illustrative implementation. Hover acronyms and technical terms for definitions.

ScopeThis page describes an illustrative implementation based on public S&P Global Ratings RMBS criteria. It is not the proprietary LEVELS model and does not reproduce licensed rating inputs or calibration tables.
Important model limitations and implementation disclaimer

This RMBS credit model is an illustrative, configurable implementation inspired by publicly available S&P Global Ratings methodology. It is not the proprietary S&P Global Ratings LEVELS model, is not certified or endorsed by S&P Global Ratings, and must not be represented as reproducing S&P ratings or S&P proprietary calibration.

The current implementation contains the following known gaps and shortcuts:

  • Rating calibration: the full S&P notch-by-notch calibration is not reproduced. Rating scenarios are configurable assumptions, and some intermediate-notch values are illustrative rather than official S&P parameters.
  • Archetype / benchmark calibration: the system has an editable archetypal pool and benchmark assumptions, but it does not reproduce S&P&#39;s proprietary historical calibration data or complete archetype-relative adjustment tables.
  • Default-frequency adjustments: the engine currently implements a practical subset of documented borrower, loan and pool factors. It does not claim to reproduce every S&P adjustment, interaction, cap, floor, segmentation rule, or sequencing rule.
  • Mortgage insurance: LMI provider ratings, coverage, claims and payout assumptions are configurable, but the implementation does not reproduce S&P&#39;s proprietary insurer-capacity, claims or counterparty calibration and is not a substitute for a licensed LMI treatment.
  • Refinancing / non-conforming risk: refinance purpose, prime/non-conforming status, first-home-buyer status and related factors are represented, but the full S&P behavioural and refinancing framework is not reproduced.
  • Credit history: the current credit-history taxonomy is simplified and does not reproduce a full historical delinquency-event model or proprietary credit-performance segmentation.
  • Geography: the postcode-to-region/state/metro reference is an editable implementation dataset. It should not be interpreted as an official S&P postcode-risk classification.
  • Loss severity: the implementation includes property valuation, MVD, foreclosure costs, recovery timing and insurance concepts, but the complete S&P recovery calibration—including all property, market, timing, legal-cost and interest interactions—is not reproduced.
  • Data-quality treatment: the platform can default missing mandatory inputs so that the illustrative model can run. This is a convenience for testing and visualization, not an assertion that missing information should be treated as benign in a production rating process.
  • Pool adjustments: originator, servicer, concentration, small-pool, data-quality and other pool-level adjustments are configurable, but the complete S&P pool-assessment framework and associated analytical judgement are not reproduced.
  • Cash-flow engine: the current outcomes are primarily collateral-credit outcomes. A full transaction-level rating analysis would additionally require monthly default and recovery timing, prepayments, interest-rate curves, fees, reserves, excess spread, liquidity, hedges and the complete priority-of-payments waterfall.
  • Capital structure: the current implementation does not reproduce a complete note-by-note capital structure and tranche cash-flow stress test sufficient to determine an official security rating.
  • Counterparty, legal and operational analysis: these are not fully modelled. A complete RMBS rating process requires separate consideration of legal isolation, counterparties, servicing, liquidity and operational risks.
  • Model governance and judgement: S&P analysts apply criteria, transaction-specific judgement and data review. Those qualitative processes are not fully automated by SIS.

Use of assumptions: values shown in Database Config are model assumptions for this application. Publicly disclosed S&P transaction examples may be used as reference points, but transaction-specific published values are not universal S&P calibration parameters. Any value labelled illustrative/configurable must be replaced or validated against the applicable licensed methodology before production use.

Purpose: this model is intended for testing, analytical prototyping, data-quality assessment and scenario exploration. It should not be used as a substitute for an S&P Global Ratings methodology, a licensed S&P model, an external rating, or investment advice.

1. Data preparation

  1. Validate mapped and defaulted model fields.
  2. Normalize balances, ratios, dates, booleans and lookup keys.
  3. Classify loans as current, reperforming or delinquent using payment status and historical indicators.

2. Loan-level default risk

For each loan and rating scenario, the model derives FF from a base-case segment assumption and applies configurable adjustments for LTV, DTI, credit score, seasoning, product, occupancy, bankruptcy, modification history and geography.

The stressed FF is capped at 100%.

3. Loan-level loss severity

The model derives a stressed property value from the available property value and a configurable MVD. It then subtracts foreclosure costs and adds configured insurance/guarantee recoveries.

LS is the resulting loss amount divided by the current balance, multiplied by the property-type factor, and then bounded by the configured floor and cap.

Ratio inputs (LTV, DTI, LMI coverage) are decimal fractions: 0.8 means 80% and 1.05 means 105%. Values above 300% (or LMI coverage above 100%) are flagged on the outcomes page as likely unconverted percentages.

4. Portfolio aggregation

Loan outputs are aggregated by balance to calculate WAFF and WALS.

WAFF = SUM(balance × FF) / SUM(balance)
WALS = SUM(balance × LS) / SUM(balance)
Projected loss = WAFF × WALS

5. Rating scenarios

Each configured rating applies a default stress multiple and a severity stress multiple. The current defaults are illustrative configuration values and are editable in Database Config.

6. Final outcomes

The outcome page shows pool balance, loan count, WAFF, WALS, projected loss and projected loss amount by rating.

The detailed loan-level results are retained for audit and Excel export.

Key terminology

RMBS

Residential Mortgage-Backed Securities.

CPR

A measure of the rate at which principal is prepaid.

LMI

Insurance that may cover eligible mortgage losses.

REO

Property held following foreclosure or repossession.

DPD

Number of days a payment is overdue.

HPI

Index used to adjust property values through time.

LEVELS

A proprietary S&P model family not reproduced in SIS.

WALS

Balance-weighted loss severity.
